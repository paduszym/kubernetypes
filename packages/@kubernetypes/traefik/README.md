# `@kubernetypes/traefik`

![NPM Version](https://img.shields.io/npm/v/@kubernetypes/traefik)
![NPM License](https://img.shields.io/npm/l/@kubernetypes/traefik)

TypeScript types for [Traefik](https://github.com/traefik/traefik/tree/master/) Kubernetes CRDs.

## Installation

For latest Traefik version:

```shell
npm install @kubernetypes/traefik
```

For specific Traefik version:

```shell
npm install @kubernetypes/traefik@<version>
```
